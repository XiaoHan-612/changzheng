择点穿行

选择一幕中的任务点直接进入。模型裁决、JSONL 日志与行军主线相同（无 MOCK）。

怎么玩

你以「过客」走进 1934–1936 年的长征节点：在暮色营地里点光点，替他们做完手头那件事；抉择与复盘交给大模型，并立刻对照史实。

核心循环

  1. 进一幕 — 过场交代时间地点，进入营地。
  2. 花暮色 — 提灯点亮任务点；行动点用尽，天黑只能启程。
  3. 做事 — 交谈、抉择、小游戏、分粮……做完一件算一件。
  4. 模型裁决 — 结果由指定大模型判断，资源与关系随之变化。
  5. 史实回响 — 对照「你经历的 / 真实发生过的 / 虚构边界」。
  6. 启程下一幕 — 于都河 → 湘江 → 遵义 → 金沙江·泸定 → 雪山草地 → 会宁。

四种模式

  • 行军模式 — 手动点任务；资源见底会掉队，高风险抉择可能有人留下。
  • 连贯行军 — 自动进入任务点；对白、抉择、玩法仍由你操作。
  • 择点穿行 — 自选某一幕的某一个任务，适合反复体验或演示。
  • 游戏模式 — 不进剧情，单独玩搭桥、钓鱼、下棋等玩法。

资源与代价

  • 体力 / 粮食 — 见底或断粮会掉队；过幕会消耗口粮。
  • 士气 / 信念 / 民心 — 影响叙事、结局倾向与老乡等支线。
  • 同伴好感 — 老班长、指导员、红小鬼、卫生员、老乡。
  • 营地侧栏 — 可看本幕目标；资源告急时会红字提示。

操作与提示

  • 点击 — 热点、选项、玩法板上的操作键。
  • 键盘 — 数字键 1/2/3 选选项；J 手记；Esc 关浮层。
  • 继续 — 叙事读完后点「继续」，再进史实回响。
  • 记录 — 顶栏「记录」可查看每次 AI 调用日志（真调可审计）。
  • 模型 — 设置里配置接口与 Key；调用失败会提示原因并可重试，无离线编造。

五幕路线
