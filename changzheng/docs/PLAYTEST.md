## 复现命令

```powershell
npm run qa:playtest -- --mode=study --strategy=balanced --runs=3 --doc   # 基线（每局 13–16 分钟）
npm run qa:playtest -- --mode=march  --runs=3                            # 行军模式失败率
npm run qa:playtest -- --speed=fast                                      # 只要功能验证时用（时钟会被压缩）
```

> `--speed=fast` 只是把"人类阅读等待"压成 0，**不能用来判断单局时长**；报时长必须用默认的 `--speed=human`。
