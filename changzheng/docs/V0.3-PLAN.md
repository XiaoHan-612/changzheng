# v0.3 迭代方案 · 全面整改

> 2026-09 体验体检后的大版本。目标：修掉玩家「不顺畅」的体感，统一玩法退出/等待契约，
> 理顺第四幕节奏，让快速模式真正能演示。**本文是本轮唯一总方案**；其他模型接手先读这里。
>
> 上一轮 P0/P1 缺陷（doRoster、cinema TDZ、waitVerdict 超时、六支 detach settle、
> 夜校 decideWithin、服务端 127.0.0.1/systemPrompt）**已验收通过**，不在本方案重复。

---

## 0. 怎么接手

1. 读完本文 §1 优先级，从「本迭代做完的」对照 §2 查漏。
2. 改代码前读 `docs/BUS.md`（加模块/玩法的唯一入口）与 `docs/HANDOFF-CODE.md`（踩坑表）。
3. 每改完一项：`npm run test:unit && npm run dev:check`；一批改完再 `npm run verify:fast`。
4. 交付前跑 `npm run verify:full`（真调五幕）。
5. 改完在本文 §2 勾选，并同步 `HANDOFF.md` §三缺口表。

**红线（别破坏）**
- 无 MOCK：AI 失败要明说 + 可重试，不编造文案。
- 状态只写 `modules/state`；流程锁只走 `withLock`。
- 玩法不自调 `/api/decide`，走宿主注入的 `decide`。
- `.env` / `runtime-config.json` 不入库。
- 服务端默认只绑 `127.0.0.1`。

## 2. P0 · 本迭代必做（12）

### P0-1 思考指示器被屏盖住（全局等待不可见）
- **位置**: `public/css/components.css` `.thinking`；`public/index.html` `#thinking`
- **问题**: 无 `position/z-index`，被 `.screen` 盖住，玩家干等无提示。
- **改法**: `position:fixed; left:50%; top:52px; transform:translateX(-50%); z-index:var(--z-toast)`。
- **验收**: 开一局点任意热点，模型调用期间顶部可见「模型在书写…」+ 秒数。

### P0-2 typeText / say 不可跳过
- **位置**: `public/js/ui.js` `typeText` / `say`
- **问题**: 终局、对白强制打字机，二周目极慢。
- **改法**:
  - `typeText` 返回 `{ promise, finish() }`；`finish` 立刻全文。
  - `say`：对白区点击或再点「继续」先 `finish`，再一次点击才推进（与过场一致）。
  - 终局段落同理。
- **验收**: 对白播字中点一下出全文，再点才进下一句。

### P0-3 抉择「继续 → 回响」双门
- **位置**: `flow/act.js` `doChoice`/`afterJudge`；`flow/echo.js`
- **问题**: 叙事点「继续」再弹回响再点「明白了」，每步两下。
- **改法**（选一，推荐 A）:
  - **A**: 去掉 `doChoice` 里 `waitBtn('继续')`，叙事后直接 `afterJudge`；回响底部按钮文案改「继续」。
  - **B**: 回响 4s 自动关 + 可点「细读」。
- **验收**: 一次抉择从选项到回到营地只点 1 次确认（含回响）。

### P0-4 原生 `confirm()` 启程确认
- **位置**: `flow/act.js` 约 430 行
- **问题**: 系统对话框，风格断裂，移动端可能被拦。
- **改法**: 游戏内二选一（「再逛逛 / 确实启程」），文案写清「将浪费 N 点暮色」；复用 `askChoice` 或 sheet-actions。
- **验收**: 剩 AP 点启程出游戏内确认，无系统弹窗。

### P0-5 `sceneImage` 首次必 fallback
- **位置**: `flow/view.js` `sceneImage`
- **问题**: 未探测成功的 primary 首次不显示，刷新才对。
- **改法**: 探测中返回 primary；`onerror` 再切 fallback。或 `onload` 后重设当前背景。
- **验收**: 清缓存进新幕，背景直接是新图（允许短暂加载）。

### P0-6 交谈：无自动聚焦 + pending 静默
- **位置**: `flow/act.js` `doTalk` / `sendTalk`
- **问题**: 要手点输入框；生成中点「说」无反馈。
- **改法**: 问候后 `input.focus()`；`talkPending` 时发送键 disabled +「等对方说完…」；快捷句同理。
- **验收**: 进交谈可直接打字；连点发送只发一条且有等待态。

### P0-7 史实未解锁仍显示全文
- **位置**: `ui.js` 史实档案渲染
- **问题**: 未解锁只降透明度，正文仍渲染，剧透。
- **改法**: 未解锁只渲染标题+日期+「完成对应节点后解锁」，不注入正文。
- **验收**: 未玩到的史实在档案里读不到正文。

### P0-8 回响不能 Esc 关
- **位置**: `main.js` Esc 列表
- **改法**: 把 `screen-echo` 加入 Esc 关闭列表；关等价「明白了」。
- **验收**: Esc 能关回响且流程继续。

### P0-9 板屏无「放弃本局」
- **位置**: `modules/games/index.js` + `public/index.html` `#screen-board`
- **问题**: 只有五子棋有认输；其余卡住只能刷新。
- **改法**:
  - 板头加 ghost 按钮「放弃本局」。
  - 点击 → `showScreen('screen-stage')` → 自动走 `destroy`/`onExit` → settle aborted。
  - 流程层对 `detail.aborted`/`why:detached`：**不调** `minigame_review`，直接短旁白回营地。
- **验收**: 任意玩法中途放弃能回营地，不烧真调、不卡锁。

### P0-10 快速模式仍过长
- **位置**: `flow/act.js` `runQuickAct` / `runForcedChain`；`data/acts.json`
- **改法**:
  - quick：forced 每幕只跑第 1 个节点 + quiz；act4 跳过 `runNightChoice`（或固定选项）。
  - quick：`afterJudge` 改为幕末一张摘要，不逐节点弹。
  - 目标：快速 ≤12 分钟（以 `qa:playtest` 为准）。
- **验收**: quick 一局五幕，节点数明显少于标准，日志无丢关键调用。

### P0-11 第四幕强制链过载
- **位置**: `data/acts.json` act4 `forced`
- **问题**: `fishing,soup,candy,sentry,path` 五连 + quiz + 夜，草地 207s。
- **改法**:
  - `soup` 已并入 fishing 收尾 → 从 forced 删 `soup`。
  - `path` 改为营地可选热点，不进 forced。
  - forced 只留 `fishing,candy,sentry`（或再减到 2）。
  - 草地 `apDays` 可升到 3，或 day2 热点从 8 减到 5。
- **验收**: `qa:board` 绿；草地实测时长下降；强制链单元测试更新。

### P0-12 附身线门槛被 forced 自动点亮
- **位置**: `flow/games-flow.js` 各 doXxx 的 `markLine`；`state.js` `canNight`
- **问题**: 强制链 fishing/candy/sentry 必跑 → 夜间 ≥3 必达成，门槛假。
- **改法**（推荐）:
  - 增加 `markLine(key, { voluntary })`；forced 调用不传 voluntary。
  - `canNight` 改为统计 voluntary ≥2（或 ≥3）。
  - 第四幕 HUD 显示「篝火夜：还需 N 条」；未达标时给静夜旁白替代，不静默 return。
- **验收**: 只走强制链时夜间不解锁；营地自愿玩过 2 支后解锁。
