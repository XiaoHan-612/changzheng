# QA 清单

## 自动化

| 命令 | 覆盖 | 通过标准 |
|------|------|----------|
| `npm run test:unit` | 资源钳制、史实解锁 | 全部断言通过 |
| `npm run qa:smoke` | 标题→营地→热点→回营地 | SMOKE PASS |
| `npm run test:e2e` | 五幕 MOCK 通关 + 不重复结算 | E2E FULL PASS，日志≥20，分汤/钓鱼各 1 次，无 pageerror |
| `npm run qa:regress` | 沙盘监听泄漏、存档回合 | REGRESS PASS |

## 手工（真调）

1. 设置 → 测试连通 → latency 显示、source=GLM  
2. 于都河：热点互动后点启程，**不得重播同一抉择**  
3. 钓鱼 3 竿可完成；史实回响可关  
4. 知识对决可答；AI 与玩家分列  
5. 终局四碎片之一；行军记录可打开  
6. 静音开关；设置清空日志后计数归零
