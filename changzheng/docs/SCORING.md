# 评分对照与路演要点

## 功能完整性与实用性 30%

- 五幕可完整通关（于都河→会宁），E2E 自动化证明
- 暮色营地探索、电影事件卡、史实回响、启程转场
- 设置：模型 / Key / 连通测试 / 清日志 / 静音
- `npm test` 单测 + 冒烟 + 全流程

## 大模型调用深度 25%

| 环节 | call_type | 是否核心 |
|------|-----------|----------|
| 进入营地氛围 | scene_gen | 是，写场景 |
| 选项倾向预告 | choice_hint | 是，卡牌预览 |
| 自由对话 | npc_chat | 是 |
| 分享/玩法裁决 | share_judge / minigame_review | 是 |
| 路线/历史节点 | branch_judge | 是 |
| 对决出题/作答/判分 | quiz_* | 是，对抗 |
| 幕间总评 / 掉队结算 | act_review / failure_review | 是 |
| 夜间 / 终局 / 研学报告 | night_* / ending_review / study_report | 是 |
| 自由行军沙盘 | sim_turn | 是（独立入口） |

- 每次调用 JSONL + 游戏内「记录」+ **答辩面板**按类型聚合 + `npm run qa:audit` 产出 schema 审计报告
- 一局**真调**约 **76** 次调用（标准模式，`npm run test:e2e` 实测），覆盖 **16 类** callType；`source=GLM`，具体模型名与推理档位见 `model` 字段，可审计
- 快速模式（每幕只跑主玩法+对决）调用更少，供 18 分钟路演（2026-09-13 实测：标准模式真调一局约 5 分钟）

## 技术创新与复杂度 10%

- 提灯焦点 + 暮色随行动点变暗（状态驱动美术）
- doneKeys 防强制链重播、withLock 防重入
- 无 MOCK：全部真调；失败重试 2 次后记 `source=ERROR`，界面提示原因并给「重试」键
- 预置角色音色 wav，自由 LLM 回复静音（可控成本）

## 业务价值与可推广性 10%

> 本节口径**只用于答辩讲述**：游戏界面按普通叙事游戏呈现，不出现合作方与行业场景字样（见 [`PITCH.md`](PITCH.md)）。

- **天津移动**：智慧文旅 / 党建研学 / 校园思政内容包
- 换 acts.json + facts.json + 场景图即可复制新史实节点
- 日志审计满足政企客户「可解释、可追溯」要求

## 团队陈述与答辩 25%

1. 30 秒讲清：不是题库，是「先入戏再对照史实」  
2. 打开**答辩面板**展示调用次数与类型  
3. 打开**行军记录**指 `source=GLM` 与 `model` 字段  
4. 演示一幕真调：对话或抉择；可选演示 ai_vs_ai 双 AI 对答  
5. 收束：教育场景可复制、日志可审计、五幕已通关；素材/音频交接给生图与音频模型，见 `HANDOFF-ART.md` / `HANDOFF-AUDIO.md`
