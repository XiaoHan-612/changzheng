# 评分对照与路演要点

## 功能完整性与实用性 30%

- 五幕可完整通关（于都河→会宁），E2E 自动化证明
- 暮色营地探索、电影事件卡、史实回响、启程转场
- 设置：模型 / Key / 连通测试 / 清日志 / 静音
- `npm test` 单测 + 冒烟 + 全流程

## 大模型调用深度 25%

| 环节 | call_type | 是否核心 |
|------|-----------|----------|
| 进入营地氛围 | scene_gen | 是，写场景 |
| 选项倾向预告 | choice_hint | 是，卡牌预览 |
| 自由对话 | npc_chat | 是 |
| 分享/小游戏裁决 | share_judge / minigame_review | 是 |
| 路线/历史节点 | branch_judge | 是 |
| 对决出题/作答/判分 | quiz_* | 是，对抗 |
| 夜间/终局 | night_* / ending_review | 是 |

- 每次调用 JSONL + 游戏内「记录」+ **答辩面板**按类型聚合
- 一局 MOCK 约 **50** 次调用；真调 `source=GLM`，具体模型名见日志 `model` 字段，可审计

## 技术创新与复杂度 10%

- 提灯焦点 + 暮色随行动点变暗（状态驱动美术）
- doneKeys 防强制链重播、withLock 防重入
- 三态 AI（MOCK/真调/FALLBACK）保证任意环境可演示
- 预置角色音色 wav，自由 LLM 回复静音（可控成本）

## 业务价值与可推广性 10%

- **天津移动**：智慧文旅 / 党建研学 / 校园思政内容包
- 换 acts.json + facts.json + 场景图即可复制新史实节点
- 日志审计满足政企客户「可解释、可追溯」要求

## 团队陈述与答辩 25%

1. 30 秒讲清：不是题库，是「先入戏再对照史实」  
2. 打开**答辩面板**展示调用次数与类型  
3. 打开**行军记录**指 `source=GLM` 与 `model` 字段  
4. 演示一幕真调：对话或抉择  
5. 收束：教育场景可复制、日志可审计、五幕已通关
