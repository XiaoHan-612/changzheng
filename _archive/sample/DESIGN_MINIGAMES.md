# 《附身·长征营地》小游戏与交互设计总案

> 目标：每个小游戏都要「有手感、有情绪、有史实落点」，不是按键凑数。  
> 硬约束：关键判定与结算叙事走 **glm-5.1**，并写入 `logs/*.jsonl`。

---

## 0. 统一设计原则（所有小游戏共用）

### 0.1 「四件套」铁律

每个附身点必须走完：

1. **他在做什么** — 入戏独白 + 情景（可跳过）
2. **你替他做** — 仅 **1 个核心操作**（最多 1 个辅助微操）
3. **glm-5.1 判定** — 输入 = 操作结果摘要 + 营地状态；输出 = 后果 + 30～80 字叙事
4. **落点** — 写营地状态 + 解锁史实卡 / 影响夜间抉择

禁止：连续 QTE、纯数值刷条、无叙事收束。

### 0.2 手感标准（抛光底线）

| 项 | 标准 |
|----|------|
| 输入延迟 | 本地即时反馈 ≤ 1 帧；AI 等待有「思考中」人格化提示 |
| 成败可读 | 成/半成/败 三档，不只二元 |
| 即时音画 | 每次有效操作有音效 + 微动效（震屏/粒子/UI 弹跳） |
| 可失败 | 允许失败；失败走模型写「代价」，不锁死进度 |
| 可重试 | 同一附身点可重开一局线；重试写入日志 |
| 无障碍 | 关键信息有文字；不靠色盲难辨的颜色单独区分 |

### 0.3 与 AI 的接口（统一 JSON）

前端小游戏结束时 **不直接写结局**，只上报操作摘要，由服务端调 glm-5.1：

```json
// POST /api/decide
{
  "scene": "老班长·咬钩起竿",
  "situation": "鱼漂第三次下沉，你在 1.2s 内起竿",
  "state": { "体力": 55, "食物": 2, "士气": 70, "信念": 85, "安全": 80 },
  "operation": {
    "type": "fishing",
    "score": 0.82,
    "detail": { "reactionMs": 1200, "timingBand": "good", "attempts": 2 }
  },
  "options": ["把鱼全煮进锅", "留半条给伤员", "只喝汤把肉留给病号"]
}
```

模型返回：`{ choice, reason, effects, narrative, factId? }`  
前端：播叙事 → 叠 effects → 开史实卡。

### 0.4 视觉/音效语言（全项目统一）

- 主色：墨青底、麻布灰、朱砂点缀、旧金高亮
- UI：卡片式话剧分镜，不用大 HUD
- 音效：环境（风/火/水）+ 操作清脆短音 + 成功低沉铜感；无 BGM 时也「有空气」
- 数字人层：当前附身角色立绘在右侧，打字节奏驱动微动

## 1. MVP 四线（首版必须打穿）

### 1.1 老班长 · 弯针钓鱼煮粥（情感主秀）

**史实锚点**：《金色的鱼钩》——老班长把鱼汤让给伤员，自己嚼草根。

#### 玩法包（三拍，只留 1 个「手感核心」）

| 拍 | 名称 | 操作 | 时长 | 是否手感核心 |
|----|------|------|------|--------------|
| A | 弯针成钩 | 拖拽针尖沿虚线弯折（3 个关键点） | 20–30s | 辅助（叙事铺垫） |
| B | 咬钩起竿 | 看漂相，在窗口期按【空格/点按】 | 15–25s | **核心** |
| C | 煮粥分汤 | 三选一分配 + 可选「自己喝不喝」 | 纯抉择 | AI 仲裁核心 |

#### B「咬钩起竿」细则

- 河面横版：水纹、浮漂、岸线；镜头轻推近漂
- 漂相三档（声音 + 动画区分，不单靠颜色）：
  - **晃**（小抖）：假信号，起竿 = 空
  - **沉**（缓沉）：真口，窗口约 **0.9–1.5s**
  - **黑漂**（急沉）：大物，窗口 **0.5–0.8s**，更难
- 计分：
  - 完美窗口内 → `score` 0.85–1.0，叙事「一条鲫鱼」
  - 偏早/偏晚 → 0.4–0.7，「小鱼或脱钩」
  - 连续空 3 次 → 强制结束，`score` 低，走「没钓到」线（仍可煮草根）
- 反馈：起竿瞬间拉弯竿稍（CSS/SVG 动画）、水花粒子、收线进度环
- **失败也推进剧情**（没鱼 → 野菜汤 → 金句仍由模型写）

#### C「煮粥分汤」细则

- 锅内可视化：米粒/草根/鱼 的「量」条
- 玩家拖动份额给：**伤员 / 全班 / 只给病号 / 自己留一点**
- 提交后 glm-5.1 判定：
  - 公平性、是否符合老班长性格、对 `食物/士气/信念` 的影响
  - 若选「自己留」：模型写「你看见老班长转过身去嚼草根」类克制叙事（护栏：不丑化战士）

#### 落点

- 状态：`食物 +`、`士气 +`、`信念 +`、伤员情况微变
- 史实卡：`h_fishhook`（金色的鱼钩）
- 可解锁篝火闲谈话题：「老班长为什么不吃饭」

### 1.2 红小鬼 · 分糖（社交与牺牲）

**史实锚点**：行军中口粮与零星食物极度珍贵；分享与让给伤员是常见叙事。

#### 玩法包

| 拍 | 操作 |
|----|------|
| 入戏 | 兜里 3 颗糖；伤员、倔强的新兵、爱哭的小号手在场 |
| 核心 | **拖糖到人物卡**（可给同一人多颗，可自留） |
| AI | 每颗糖的接受/拒绝/转赠 + 整局道德评价 |

#### 细则

- 三张人物状态条：伤情、情绪、是否「嘴硬不肯收」
- 拖拽手感：糖跟随指针、落点高亮、回弹动画
- **AI 逐颗判定**（一次调用可返回 3 条，或分 3 次——首版 1 次调用返回数组，日志记 1 条 + `items:3`，保证调用深度可辩）
- 特殊分支：
  - 全给伤员 → 高信念
  - 给倔强新兵 → 模型写「他先推开，后来在你走不动时递了水壶」
  - 全自留 → 不惩罚羞辱，写「夜里你把糖纸攥皱了又抚平」——情绪复杂度，不是道德说教按钮

#### 落点

- `士气/信念`、与 3 人关系值（影响夜间谁帮你说话）
- 史实卡：`h_share`（行军中的分享与口粮）

---

### 1.3 哨兵 · 夜岗（紧张节奏）

**史实锚点**：夜间警戒、口令、防敌特与野兽；误报与漏报都是严重问题。

#### 玩法包

| 拍 | 操作 |
|----|------|
| 入戏 | 暗夜营地边缘；风声、虫鸣；你持枪靠在树/哨位 |
| 核心 | **事件流：听/看 → 判断「敌 / 友 / 兽 / 风」→ 报 / 不报** |
| AI | 整段岗哨表现综合判定 + 叙事 |

#### 细则（做成「三感哨位」）

时长约 60–90s，固定 5 个信号，顺序随机但史实合理：

1. **脚步远近**（音频波形/远近指示器）— 缓慢多点 = 巡逻自己人；急促 = 可疑  
2. **口令对答**（文字）— 给上句，你选下句（营地日间若上过「识字/口令」线，这里**记得你学过的口令**）  
3. **光点**（屏上微弱闪点）— 烟头 = 友；双闪 = 可疑  
4. **动物**（低吼）— 不报  
5. **静默陷阱**（什么都不发生）— 选「乱动暴露位置」= 失误  

计分：正确处置数 / 误报 / 漏报 → `score` 与 `安全` 值。

- 视觉：暗角、手电锥形可照（鼠标），照到才给细节；不照也能靠声音判  
- 音：立体声耳机友好（左右声道区分方向）；无耳机时补方向箭头  
- AI 判定示例：`安全-` 时夜间抉择出现「加岗」

#### 落点

- `安全`、`士气`；可能影响夜间是否「有惊无险」
- 史实卡：`h_sentry`（警戒与口令）

---

### 1.4 文化教员 · 夜校识字（教育向，易做细）

**史实锚点**：红军行军途中办识字班，用具名、地名、口令当课本，「识字就在背包上、路旁」。

#### 玩法包

| 拍 | 操作 |
|----|------|
| 入戏 | 灯下/火边，几名战士伸头看一块小黑板/沙地 |
| 核心 | **三小关连打（总 45–60s）**：认字 → 听音选字 → 教写/读口令 |
| AI | 教学效果评价 + 是否把「今晚口令」编成可记的句子 |

#### 细则

**关 A 认字**（看图/部件）  
- 给一个字或词：`志 / 胜 / 同志 / 瑞金`  
- 3 选 1；答对字旁有「木棍在沙上描红」动画  

**关 B 听音选字**  
- 点播放（Web Speech 或预置发音描述卡；无 TTS 时用拼音+声调图示）  
- 选正确汉字  

**关 C 教口令/地名**  
- 系统给今晚口令的含义，你 **从字块拼出一句话**（拖拽排序）  
- 拼对 → 篝火旁战士跟读一句（打字机）  
- **写回哨兵线**：口令进入全局 `tonightPassword`

难度：默认简单（教育向）；可选「加练」多 2 题（不影响通关）。

#### 落点

- `士气+`、`信念+`；解锁口令 → 哨兵线加成
- 史实卡：`h_nightschool`（行军中的文化学习）

## 2. 夜间抉择（MVP 必做，算「一局」收束）

四线结束后进入 **篝火·深夜**。

- 展示营地状态仪表（食物/士气/安全/伤员）
- 生成 **2～3 个互斥抉择**（**必须由 glm-5.1 生成**，禁止写死选项）  
  示例 prompt 要点：基于你已完成的附身线、分糖/分汤结果、哨位安全、是否学会口令
- 选择后再 **一次模型调用** 写「当夜之后」
- 进入终局三碎片之一：**守望 / 同行 / 未竟**（规则由模型按状态映射，前端只做表现）

## 3. P2 扩展小游戏（生态加厚，模板已定）

| 角色 | 核心操作（只 1 个） | AI 点 | 优先级 |
|------|---------------------|-------|--------|
| 指导员 · 行军图 | 走格迷宫画路线（避沼泽/选近远） | 路线优劣与风险仲裁 | P2-1 |
| 军需处长 · 丰碑 | 无操作，纯三幕抉择 | 让给谁 + 结局叙事 | P2-1 |
| 打水漂 | 力度条+角度松手，计距离与次数 | 输赢对士气的评价 | P2-2 |
| 打草鞋 | 选料+编底节奏点 | 补给谁 | P2-2 |
| 司号员 | 节奏按键复现号谱 | 传令是否清晰 | P2-3 |
| 卫生员 | 拖拽包扎顺序 | 伤情判断 | P2-3 |
| 电报员 | 摩斯点按抄录 | 情报真伪 | P2-3 |

P2 仍遵守：一附身点 = 1 操作 + ≥1 次模型调用 + 史实落点。

## 4. 交互话剧壳（不是传统 HUD）

```
┌─────────────────────────────────────────────┐
│  场景插画（营地黄昏/河边/夜哨/雪…）           │
│         ┌──────────────┐                    │
│         │  立绘·老班长  │   状态：饭2 士气70 │
│         └──────────────┘                    │
│  ┌───────────────────────────────────────┐  │
│  │ 对话/操作区（唯一主交互面）              │  │
│  └───────────────────────────────────────┘  │
│  [附身] [史实] [行军记录]        AI·glm-5.1 ● │
└─────────────────────────────────────────────┘
```

- 右上角 **AI 指示灯**：思考中闪烁；成功日志 +1  
- 「行军记录」全屏可回放每条调用（答辩神器）

## 5. 完成度分级（我对「做成啥样」的承诺）

| 等级 | 内容 | 对应 |
|------|------|------|
| L1 可玩 | 四线全通、夜间抉择、终局、日志 | 参赛底线 |
| L2 手感 | 漂相三档、拖糖回弹、暗夜听感、描红动画 | **目标交付** |
| L3 抛光 | 粒子、镜头微推、音效分层、失败情绪文案 | 有时间就上 |
| L4 生态 | P2 角色池 + 状态解锁新线 | 加分项 |

**首版冲 L2**，不把 L3/L4 当成能交的借口。

## 7. 风险与对策

| 风险 | 对策 |
|------|------|
| 无 Key / 模型慢 | 演示模式 MOCK；真调失败自动降级并 **标明 FALLBACK** |
| 小游戏像 QTE | 每线只 1 操作；失败必有叙事落点 |
| 剧情说教 | 文案克制、第二人称、不堆口号；史实与虚构分栏 |
| 口令/识字无发音 | 拼音+声调图示，不依赖 TTS |
| 评委问「AI 在哪」 | 随时打开行军记录，指 source=GLM-5.1 |
