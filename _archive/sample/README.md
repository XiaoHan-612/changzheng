# 《星火微光 · 我路过他们的长征》

赛道二 · AI 游戏：可附身的长征营地情景话剧。  
玩家以过客之眼附身营地中的战士（下棋 / 交谈 / 钓鱼 / 看图 / 站岗），替他走完这一段；  
**全部智能决策运行态调用 glm-5.1，并写入 `logs/` 日志。**

## 快速启动

```bash
cd "竞赛题目，请完成，高要求"
npm install          # 首次
copy .env.example .env
# 编辑 .env：填入 GLM_API_KEY（天津移动指定接口）
npm start
```

浏览器打开 **http://localhost:3000**

无 Key 时自动 **演示模式（MOCK）**，流程可完整跑通；正式演示必须配置真实密钥。

## 一局怎么玩

1. **进入营地** → 篝火广场  
2. 选择附身（建议至少 3 条线）：  
   - **老班长**：弯针 → 咬钩起竿 → 分汤（AI 仲裁）  
   - **红小鬼**：三颗糖分给谁（AI 判定）  
   - **夜岗战士**：五个信号（口令与夜校联动）  
   - **文化教员**：识字三关，写出今晚口令「瑞金」  
3. **夜间议事**（≥3 线后解锁）：选项由模型生成 → 当夜叙事  
4. **终局** 守望 / 同行 / 未竟 + 行军记录回放  

## 赛制合规

| 要求 | 实现 |
|------|------|
| 运行态调 glm-5.1 | `server/ai.js` → `POST /api/decide` |
| 每次调用有日志 | `logs/ai-calls-*.jsonl` + `session-full.jsonl` |
| AI 在决策核心 | 对话、抉择、小游戏结算、夜间选项、终局均走模型 |
| 可完整一局 | 附身线 + 夜间 + 终局 |

游戏内右上角 **行军记录** 可逐条查看 `source`（`GLM-5.1` / `MOCK_AI` / `FALLBACK`）。

## 环境变量

| 变量 | 说明 | 默认 |
|------|------|------|
| `GLM_API_KEY` | 天津移动 glm-5.1 Key | 空 → MOCK |
| `GLM_API_URL` | 接口 | bigmodel.cn chat/completions |
| `GLM_MODEL` | 模型名 | glm-5.1 |
| `PORT` | 端口 | 3000 |

## 目录

```
server/     Express + glm 代理 + 日志
public/     话剧 UI + 四个小游戏
data/       史实（可扩展）
logs/       AI 调用日志（JSONL）
DESIGN_MINIGAMES.md  小游戏设计总案
```

## 设计说明

- 历史真实性优先；档案中「真实史实 / 虚构互动」分栏  
- 每条附身线只保留 **一个核心操作**，避免 QTE 拼盘感  
- 无外部美术：CSS 水墨麻布风 + 立绘字位
