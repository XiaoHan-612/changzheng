# 《长征·抉择》草地章节 Demo

完整章节：**第二幕 · 草地 · 金色的鱼钩**

交互形态：**全景热点探索**（不再是列表按钮）+ **史实回响**（操作完立刻对照真实史实）

## 启动

```powershell
cd demo
npm install
npm start
# 浏览器打开 http://localhost:3001
```

无 `GLM_API_KEY` 时自动 MOCK；配置 `.env` 后为真实调用。

## 怎么玩

1. 过场 → 进入 **营地全景**，光点在呼吸  
2. 点击热点：
   - **池塘边** — 钓鱼小游戏（漂相三档）
   - **夜校** — 识字三关，写回口令
   - **篝火旁** — 交谈 / 分一口粮
   - **背囊旁** — 休息
   - **东边小路** — 继行军（下一营地日 / 强制节点）
3. 每次 AI 裁决后立刻弹出 **「史实回响」**：你刚经历的 / 真实发生过的 / 虚构边界  
4. 强制链：钓鱼分汤 → **图上点选路线** → 知识对决 → 夜间抉择 → 结局  
5. 右上角「行军记录」回放每次调用

## 赛制合规

| 要求 | 实现 |
|------|------|
| 运行态调 glm-5.1 | `server/ai.js` → `POST /api/decide` |
| 每次调用有日志 | `logs/*.jsonl` + 游戏内行军记录 |
| AI 在决策核心 | 对话、分享、小游戏结算、路线、出题、判分、夜间、结局 |
| 可完整一局 | 营地日经营 + 强制链 + 多结局 |
